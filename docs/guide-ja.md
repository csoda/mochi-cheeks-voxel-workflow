# ボクセルキャラクター制作ガイド

**原画を空間に置いてから立体を作る。顔や体をOKしたら、その部分を固定して次に進む。** この手順はオリジナルのちびキャラに向いています。キャラのモデリングを自動化するものではありません。

| 段階 | やること | 次に進む前に見るもの |
|---|---|---|
| 1. 原画 | 正面・斜め前・真横・斜め後ろ・背面と、真上。各1枚に切り出す | 立ち方・顔・髪の形。真上は奥行きの参考に留める |
| 2. Blender配置 | 足裏の高さ、靴の中心、全高をそろえて、6枚を空間に置く | 同じ縮尺の正投影。髪を含む外接枠の中央を足の中心と間違えない |
| 3. 立体 | 頭・髪・体・衣装を厚みのあるブロックで別々に作る | 真横・斜め後ろ・真上。髪のカールに空間があるか、胴と後ろ髪が一枚板になっていないか |
| 4. 顔 | 原画に **目元→鼻先** と **鼻先→頬・口元→顎** の2本を引く。同じカメラで比較しながら奥行きを整える | 鼻を変えるだけでなく、目元のくぼみと下の丸みも見る。正面と反対側も確認 |
| 5. 動き | 静止形が決まったら骨を入れる。待機、歩行、ジャンプを別アクションにする | 足裏の接地、膝・腕のつながり、顔がゆがまないか。手やブーツにスカートが引っ張られないか |
| 6. 出力 | 静止は `.vox`、編集・動きは `.blend`、必要ならアニメ入り `.glb`。比較画像も作る | 出した版を開き直す。プレビューとモデルの版を揃える |

### 原画の配置だけ先に作る

1. [ひな型](../skills/voxel-character-workflow/assets/reference-manifest.example.json)をリポジトリ直下の `manifest.json` にコピー。正面〜背面の5枚と真上のPNGを用意し、ファイル名を差し替える。原画は透明背景が使いやすい。
2. 正面から背面まで、PNGの上から測った「頭のてっぺん」「靴底」と、左から測った「靴底の中心」を入力する。端から何ピクセルかで指定する。PNGごとに寸法が違ってもよい。真上はキャラの前が画像の下になるよう回してから登録する。真上の `anchor_px` は基準点の画像内座標（左・上から）、`anchor_world_xy` はその点を置くBlenderのXY。`units_per_px` は画像1ピクセルが何単位か。例えば、頭幅32単位に対して画像の頭幅が160pxなら `0.2`。
3. Blenderが使える端末で、このリポジトリのルートから実行する。`blender` がPATHに無ければインストール済みBlender実行ファイルのパスを使う。出力先は**新規ファイル**。

```sh
blender --background --python-exit-code 1 --python skills/voxel-character-workflow/scripts/register_blender_refs.py -- manifest.json Character_Refs.blend
```

4. 開いたら「01 · REFERENCE PLANES」の各 `REF` を目のアイコンで切り替え、対応する `ORTHO` カメラを選んでアクティブにする（3Dビューで選択して `Ctrl + テンキー0`）。画像の色を見るにはマテリアルプレビューを使う。レンダー用のカメラアイコンは、アウトライナーのフィルターで表示して切り替える。6枚とも内蔵なので、元PNGなしで `.blend` を開ける。このヘルパーが作るのは新規の参照シーンのみで、既存のBlenderファイルは開いたり変更したりしない。

### 引き継ぎの判断

再利用できるのは、原画の配置、輪郭の見方、立体やモーションの検証、近い体型なら歩行のタイミング。頭・髪・衣装のブロック配置や、関節位置と重み付けはそのキャラごとに作る。足が床に着いても、その場歩きで足が前後するのは正常。ゲームには必要に応じてルート移動を別途合わせる。元絵の再現度も実機の負荷も、この手順だけで保証はしない。

テスト用の画像で先に試すなら、[READMEの実行例](../README.md#すぐ試す)へ。登録画像と実際のカメラを検証するコマンドもあります。

Codexに依頼するときの例：**「この制作手順で、原画をBlenderに置くところから。今回は静止モデルまで。顔をOKするまでは動かさない」**。
